LumenCode

Structural code explorer for local source trees

Linux · macOS · Windows Beta

Explore the shape of your code

LumenCode reads a local source tree and lets you drill from folders to files, symbols and member details. Browse declarations, inspect syntax-coloured source snippets, and follow relationships across files.

It is a code explorer rather than an editor. The Linux, macOS and Windows interfaces share the same parser-assisted analysis engine, including its language heuristics and recovery for incomplete code.

Language support

Explore projects in PHP, JavaScript, TypeScript, TSX, QML, CSS, HTML, JSON, Python, C/C++, Java, C#, Rust, Swift, Objective-C and more. Support combines Tree-sitter parsers with language-specific heuristics; the available detail varies by language.
