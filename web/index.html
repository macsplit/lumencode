LumenCode

Structural code explorer for local source trees

Linux · macOS · Windows

Select an image to view it full size.

Explore the shape of your code

Browse local source trees, inspect symbols and syntax-coloured code, and follow relationships across files. Native Linux, macOS and Windows interfaces share one analysis engine, with language-specific heuristics and recovery for incomplete code.

Language support

Explore projects in PHP, JavaScript, TypeScript, TSX, QML, CSS, HTML, JSON, Python, C/C++, Java, C#, Rust, Swift, Objective-C and more. Support combines Tree-sitter parsers with language-specific heuristics; the available detail varies by language.
